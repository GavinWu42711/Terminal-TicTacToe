# **TicTacToe**
<img width="122" height="247" alt="image" src="https://github.com/user-attachments/assets/6a96e1eb-eef7-49f7-8143-1d49e1acd1a9" />

This is TicTacToe game I programmed in C to get better at C to do embedded programming. In the repository, there is an uncompiled and compiled version of the code. The game is played in terminal, 
with each player taking turns placing their "tile" (X or O) on the board until one of them gets 3 in a row first! 

To place a tile on your turn, enter the number for the respective square shown on the board outputted to terminal. To restart/clear the board, enter Y. To stop the game, enter N. GLHF!
